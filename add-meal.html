How to model a meal

Recommended structure

  • Use one ingredient row for each distinct thing you expect Giant Eagle to add to the cart.
  • Keep the ingredient name human-friendly, then tune the cart query for the exact store search term.
  • Use cart quantity for how many packages or units should be added, not the recipe measurement.
  • Use planner sides for the text you want to see on the weekly planner card.

Useful metadata

Fields that help automation

Brand, size, department, and notes are optional, but they give the browser runner better search hints and make skipped items easier to review.
